# Guarded chaotic workload transformation

This is a new, lower-intensity variant of the D1 window at `data/phpa/phpa-datasets/chaotic_1_base_pods35_chaos_level1.2_seasonality_strength0.4_trend_changes8_noise_level0.7_test.csv` (rows 284–325). It uses `target_rps = 10 + 35 * (pod_count - 11) / (100 - 11)`, retaining the same 42 bins, their order, and 90× time compression. The exact replay and request schedule were frozen before any controller run: replay SHA-256 `3e8d234b021e53446b9c9d8b2891bd3bce5205724cf4c3ef2c6c9d57e6043ed0`; schedule SHA-256 `79db2b7c2e8ca93c3f40dcfed88154a7da76eb66e8a6686a69ced4d05096639d`; 12532 measurement requests. The hard ceilings are 45 RPS and 256 in flight, with the existing five-second timeout, 120-second warmup, and 420-second measurement. Results are not replicates of the prior 20–120 RPS variant.
